# Cursor project config

This directory holds **Cursor IDE** settings for this repo.

- **Rules** — [`.cursor/rules/`](rules/) contains `.mdc` rule files (YAML frontmatter). Cursor loads them according to each file’s scope and `alwaysApply` flags. When editing rules, follow [`rule-authoring.mdc`](rules/rule-authoring.mdc).

- **Contributor guide** — Mental model, diagrams, automations, and plugins: [docs/cursor-agent-workflow.md](../docs/cursor-agent-workflow.md).
